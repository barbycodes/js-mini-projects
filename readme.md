# 🧠 JavaScript Mini Projects Collection

A collection of beginner-friendly JavaScript projects built with HTML, CSS, and JavaScript.  

---

## 🔤 Confirm the Ending Tool

A simple JavaScript tool with a small interactive UI that checks whether a string ends with a given target string.

### Features
- String ending validation using JavaScript
- Simple interactive input fields
- Instant result display with color feedback

---

## ✂️ Truncate String Tool

A tool that truncates a string to a given length and adds "..." if it exceeds the limit.

### Features
- String truncation using JavaScript
- User input for text and max length
- Instant result display

---

## 📅 Leap Year Calculator

A simple tool that checks whether a given year is a leap year based on standard rules.

### Features
- Leap year validation logic
- User input for year checking
- Instant result display
---

## 🃏 Card Counting Assistant

A casino-style app that tracks card values and suggests betting decisions.

### Features
- Global count tracking
- Card evaluation (2–10, J, Q, K, A)
- Automatic “Bet” or “Hold” decision

---

## ✉️ Email Masker Tool

A tool that hides part of an email username using asterisks for privacy.

### Features
- Email masking with string methods
- Username and domain separation
- Input validation

---

## 🧮 Calculator App

A basic calculator that performs arithmetic and advanced operations.

### Features
- Addition, subtraction, multiplication, division
- Square and square root functions
- Button-based interactive UI
